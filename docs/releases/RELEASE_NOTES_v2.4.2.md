# OBS AirPlay v2.4.2

A small release for the update prompt. Nothing changes in AirPlay itself.

## Fixes

- **Update alerts show OBS's icon.** The update prompt and the alert that follows it showed a blank placeholder icon. They now carry the icon of the running OBS.

The alerts you see while installing this release still come from the version you have, so the icon first appears with the update after this one.

## Updating

- **From v2.4.0 or later:** click **Install Update** in the prompt, then quit OBS when it suits you. The plugin is replaced as OBS quits.
- **From v2.3.0 or earlier:** close OBS Studio, download the Apple silicon `.pkg` installer, run it, and reopen OBS.

## Compatibility

- macOS 12 Monterey or later
- OBS Studio 28 or later
- Apple silicon (`arm64`)
