# OBS AirPlay v2.4.1

A maintenance release with no changes to AirPlay itself. It is the first release that v2.4.0 can install on its own.

## If you have v2.4.0

The update prompt offers **Install Update**. Click it, wait for "OBS AirPlay 2.4.1 is ready", and quit OBS when it suits you. The plugin is replaced as OBS quits; the next start logs `OBS AirPlay Plugin loaded (version 2.4.1)`.

## If you have v2.3.0 or earlier

Close OBS Studio, download the Apple silicon `.pkg` installer, run it, and reopen OBS. Later releases can then be installed from the prompt. See the [v2.4.0 release notes](https://github.com/LZlamian/OBS-AirPlay-Plugin/releases/tag/v2.4.0) for how updates work.

## Compatibility

- macOS 12 Monterey or later
- OBS Studio 28 or later
- Apple silicon (`arm64`)
